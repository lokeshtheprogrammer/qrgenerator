# QR Code Generator

This project is a QR code generator that allows users to create QR codes for various types of data such as URLs, text, contact information, and more. The application is easy to use and provides a simple interface to generate and download QR codes instantly.

## Features
- Generate QR codes for URLs, text, email, and more.
- Download QR codes in various formats.
- User-friendly interface.
